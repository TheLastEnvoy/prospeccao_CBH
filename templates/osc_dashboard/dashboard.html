Como usar o Dashboard
Filtros de Pesquisa
  • Município: Selecione múltiplos municípios
  • Natureza Jurídica: Selecione múltiplas naturezas jurídicas
  • Palavras-chave: Adicione múltiplas palavras para busca no nome
  • Naturezas para Visualizar: Campo alternativo para seleção múltipla (Ctrl+clique)
Ações Disponíveis
  • Filtrar Dados: Aplica os filtros selecionados
  • Exportar Excel: Baixa dados filtrados em Excel
  • Limpar Filtros: Remove todos os filtros
  • Mostrar/Ocultar Mapa: Exibe mapa interativo
Usando o Mapa
  • • Cores: Indicam quantidade de OSCs por município
  • • Clique: Seleciona o município e aplica filtro
  • • Hover: Mostra informações do município
  • • Zoom: Use a roda do mouse ou controles do mapa
Dica: Use Enter no campo de palavras-chave para pesquisar rapidamente!
